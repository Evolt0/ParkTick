# ParkTick 变更记录

## 2026-11-02：可达环境完整回归与修复（未正式验收）

- 原绿牌漏字改用有界 CTC 前缀束搜索修复，保持真实模型与原精确期望；处理重复字符、复用结果重置、非法张量和未定义标签，按有效行归一化 MNN 浮点输出与置信度，不注入样本字符。
- 修复配置变更误取消拍照草稿、权限拒绝后旋转重新请求，以及低版本大字横屏下拍照 / 权限页无法滚动的问题。
- 确认登记与取消收起输入法，首页不自动弹出搜索键盘，保留明确返回与原拍照时间。
- 复现并修复快速回前台没有经过 STOP 时漏掉照片清理重试的问题；改为 ON_RESUME 触发，成功恢复只按通知实例身份清理旧警告，不覆盖新提示。
- 永久回归为 8 项本地规则检查、13 项 Room / 文件生命周期检查及 3 项真实识别检查；API 24、API 36 和 API 35 16KB 环境各 16 项 Android 检查通过。
- 实际验证事务失败回滚、提交后照片删除失败 / 恢复、相机照片写入失败 / 重试、最低版本升级与重启持久化；16KB 模式下 ARM64 翻译运行混淆 Release，精确蓝 / 绿牌与 JNI 构造器探针通过。临时故障与 Release 诊断代码已移除，标准 runner 已恢复。
- 保留质量差距：固定公开挑战集蓝牌 26/30、绿牌 11/30 整牌正确，不是泛化准确率；普通黄牌 30 张合法样本、原生 ARM 与两台目标手机的正式验收仍未关闭。APK 哈希、性能观察及 A-01 至 A-23 边界见[回归验证记录](verification.md)。

## 2026-10-31：开发验证构建（未正式发布）

### 新增

- Kotlin / Compose / CameraX / Room 原生 Android 工程、正式生成的 Gradle Wrapper、版本目录、依赖锁和 SHA-256 校验元数据。
- 首页、拍照、停车详情、历史四个业务目的地，明确返回按钮；车牌确认采用拍照页内的可编辑弹窗，不增加修改页面或二次登记确认。
- CameraX 捕获开始时间锚点，保存成功后采纳；模型和确认耗时计入停车时长。
- 最终规范化车牌的在停唯一约束；重复登记打开原记录，不替换照片或时间；结束后的同牌停车创建独立记录。
- 结束确认、历史事务与可恢复删除任务；保存失败回滚、删除失败单独反馈、旧任务不误删同牌新照片。
- 同 boot 单调计时，跨重启明确估算，不可靠时间显示未知；退出、锁屏、强停或重启不依赖后台计时服务。
- 在停升序、历史按结束倒序、字面量车牌搜索；历史不提供照片或结束入口。
- 固定来源的 HyperLPR / MNN / OpenCV 源码构建、自有 JNI、六个随包模型与实际第三方许可归档；无 INTERNET 权限，不写系统相册，显式排除标准备份和迁移。

### 修复与交互调整

- 16 位 PNG 可能忽略 `inPreferredConfig` 返回 `RGBA_F16`：统一 sRGB，仅在必要时转换成 JNI 所需的 8 位 RGBA，避免普通 JPEG 整图重复复制。
- JNI 使用 scoped context ownership、像素解锁与 buffer RAII，初始化失败显式传播；推理串行复用 context，关闭可重复调用。
- 修复检测网络忽略配置线程数，推理明确采用 CPU 后端。
- 200% 字体下返回 / 标题 / 历史分行布局；确认照片为缩略图，弹窗处理安全区域与键盘 inset。
- 首页使用不覆盖内容的底部文字操作，搜索与记录在同一可滚动列表；不缩小系统字号绕过布局问题。
- 草稿归属与应用级收尾任务避免取消、迟到回调或 ViewModel 清理误删正式照片；进程恢复清理遗留孤儿文件。

### 兼容性与验收边界

- minSdk 24，compile / targetSdk 36；Release 包含 ARM64 / ARMv7，Debug 另含 x86_64。使用 NDK r28c，所有打包的 64 位 native ELF 与 APK 静态 16KB 对齐检查通过。
- 已生成标准 debug 签名 APK、未签名 R8 Release 和测试证书签名的 R8 Release；测试证书不作为正式生产签名。
- 已执行本地单元、真实 Android Room、生产模型与模拟器实际交互验证；**Android 检查仍有绿牌漏字失败，不是全绿状态**。
- 坚果 Pro 3、Redmi Note 14 Pro 5G（天玑 7300-Ultra）、ARM / 16KB 实际运行、三类各 30 张合法标注样本及完整性能 / 内存统计尚未完成，不宣称正式放行。

具体证据、失败样本、APK 校验值和 A-01 至 A-23 的覆盖边界见[运行验证记录](verification.md)；构建方法见[构建与安装](../runbooks/android-build.md)。
